# パパごはんアルバム

スマートフォンで、パパが作ってくれたごはんを写真・料理名・主な材料・日付だけで記録する小さなWebアプリです。

## ファイルの役割

- `index.html`: 画面の骨組みです。ボタン、入力欄、料理一覧、下のタブを置いています。
- `style.css`: 見た目の設定です。スマートフォンで押しやすく、明るい家族向けの色にしています。
- `script.js`: 料理の保存、編集、削除、検索、ランダム選択、写真の縮小を動かします。
- `manifest.json`: ホーム画面へ追加するためのPWA設定です。
- `service-worker.js`: アプリ本体を端末に保存し、オフラインでも開けるようにします。
- `icons/`: ホーム画面に表示するアイコンです。

## できること

- 「今日のごはんを記録」から、料理写真・料理名・材料・日付を保存できます。
- 写真は保存前にスマートフォン表示向けへ縮小し、IndexedDBへ保存します。
- 登録した料理は新しい日付順に表示します。
- 料理名または材料で検索できます。
- 料理の編集と削除ができます。削除前には確認が出ます。
- 「今日なに食べたい？」で、登録済みの料理から1品をランダムに選べます。

## パソコンでの開き方

1. このフォルダを開きます。
2. 簡易サーバーを起動します。
   ```bash
   python -m http.server 8000
   ```
3. ブラウザで `http://localhost:8000` を開きます。

## 同じWi-Fiのスマートフォンから確認する方法

1. パソコンとスマートフォンを同じWi-Fiにつなぎます。
2. パソコンのIPアドレスを確認します。
   - Windowsなら、ターミナルで `ipconfig` を実行し、Wi-Fiの `IPv4 アドレス` を見ます。
3. パソコンで簡易サーバーを起動します。
   ```bash
   python -m http.server 8000 --bind 0.0.0.0
   ```
4. スマートフォンのブラウザで `http://パソコンのIPアドレス:8000` を開きます。

例: パソコンのIPアドレスが `192.168.1.23` なら、スマートフォンで `http://192.168.1.23:8000` を開きます。

## ホーム画面へ追加

スマートフォンのブラウザで開いたあと、共有メニューやブラウザメニューから「ホーム画面に追加」を選ぶと、アプリのように開けます。

## 大切なこと

写真と料理データは、この端末のIndexedDBに保存されます。ログインやクラウド同期はなく、外部サーバーへ送信しません。
